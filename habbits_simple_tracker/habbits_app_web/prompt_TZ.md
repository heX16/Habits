# техническое задание на веб-приложение для **учёта привычек**

NOTE: Это ТЗ устарело, но оставлено для истории.

## **1. Общая информация**
Приложение предназначено для учёта привычек (вредных и полезных). Пользователь сможет отмечать выполнение привычек по дням, редактировать список привычек и просматривать данные за последние 7 дней. В дальнейшем планируется добавление дополнительных статусов привычек.

---

## **2. Технологический стек**
- **Backend**: Python + Flask
- **Frontend**: HTML, CSS, JavaScript (без фреймворков)
- **База данных**: SQLite

---

## **3. Функциональные требования**

### **3.1. Главная страница (учёт привычек)**
- Таблица, где:
  - Столбцы представляют собой дни (диапазон дат задаёт frontend).
  - Строки представляют собой привычки.
- Каждая ячейка таблицы может содержать:
  - Числовое значение (0, 1, ... в будущем другие статусы).
- При клике на ячейку:
  - Переключение статуса (например, 0 → 1 → 0).
  - Изменение отправляется в **Backend** и сохраняется в базе данных.
- При загрузке страницы:
  - **Frontend** запрашивает у **Backend** данные о привычках и их статусе за определённый диапазон дат.

---

## **4. API (Взаимодействие Frontend и Backend)**

### **4.1. Получение данных о привычках (с диапазоном дат)**
- **Запрос**:
  ```
  GET /api/habits?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD
  ```
- **Параметры запроса**:
  - `start_date` – начальная дата диапазона (например, `2025-02-01`).
  - `end_date` – конечная дата диапазона (например, `2025-02-07`).
- **Ответ**: JSON-объект со списком привычек и их статусом в виде массива.

#### **Пример JSON-ответа:**
```json
{
  "start_date": "2025-02-01",
  "end_date": "2025-02-07",
  "habits": [
    {
      "id": 1,
      "name": "Утренняя зарядка",
      "tracking": [1, 0, 1, 1, 0, 0, 1]
    },
    {
      "id": 2,
      "name": "Чтение книг",
      "tracking": [0, 1, 1, 0, 0, 1, 1]
    }
  ]
}
```
- `tracking` — массив значений, соответствующих статусу привычки за запрашиваемый диапазон дат.

### **4.2. Обновление статуса привычки**
- **Запрос**:
  ```
  POST /api/habits/update
  ```
- **Тело запроса (JSON)**:
  ```json
  {
    "habit_id": 1,
    "date": "2025-02-03",
    "status": 1
  }
  ```
- **Ответ**: Подтверждение обновления.

### **4.3. Добавление новой привычки**
- **Запрос**:
  ```
  POST /api/habits/add
  ```
- **Тело запроса (JSON)**:
  ```json
  {
    "name": "Новая привычка"
  }
  ```
- **Ответ**: Подтверждение добавления.

### **4.4. Удаление привычки**
- **Запрос**:
  ```
  DELETE /api/habits/delete
  ```
- **Тело запроса (JSON)**:
  ```json
  {
    "habit_id": 1
  }
  ```
- **Ответ**: Подтверждение удаления.

## **5. База данных (SQLite)**

### **5.1. Таблица `habits` (Список привычек)**
| Поле       | Тип    | Описание                |
|------------|--------|-------------------------|
| `id`       | `INTEGER PRIMARY KEY AUTOINCREMENT` | Уникальный идентификатор |
| `name`     | `TEXT NOT NULL` | Название привычки |

### **5.2. Таблица `habit_tracking` (Отметки выполнения)**
| Поле       | Тип    | Описание                         |
|------------|--------|----------------------------------|
| `id`       | `INTEGER PRIMARY KEY AUTOINCREMENT` | Уникальный идентификатор |
| `habit_id` | `INTEGER NOT NULL` | ID привычки (FK → habits.id) |
| `date`     | `TEXT NOT NULL` | Дата в формате `YYYY-MM-DD` (Уникальный ключ в паре с habit_id) |
| `status`   | `INTEGER NOT NULL DEFAULT 0` | Статус привычки (0 - не выполнено, 1 - выполнено, в будущем другие статусы) |
| **UNIQUE (`habit_id`, `date`)** | | Индекс для быстрого поиска |
