## Архитектурные особенности

### 🎯 Новые паттерны
- **Popup Navigation Pattern** - StatusMenuPopup как модальное окно выбора
- **CRUD Operations Pattern** - полный набор операций с привычками через UI
- **Multi-Screen State Management** - синхронизация данных между экранами
- **Confirmation Dialog Pattern** - безопасное удаление с подтверждением

### 📱 Kivy-специфичные решения
- Использование **ScreenManager** для навигации между экранами
- **Popup** виджеты для модальных диалогов (StatusMenuPopup, ConfirmationDialog)
- **ScrollView** для длинных списков привычек
- **Dynamic Layout Building** - программное создание UI компонентов
- **Event Binding** - связывание событий между виджетами и экранами

### 🔄 Цикл обработки двойного клика
```
StatusCell (двойной клик) → HabitRow (событие) → MainTrackerScreen (обработка)
     ↓
HabitsModel.get_habit_data() → StatusMenuPopup.show_for_cell()
     ↓
Пользователь выбирает статус → StatusMenuPopup закрывается
     ↓
MainTrackerScreen.on_status_selected_from_menu() → HabitsModel.update_habit_status()
     ↓
UI обновляется → Статус изменен в базе данных
```
