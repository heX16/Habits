### 📦 Основные компоненты

#### 1. **main.py** - Точка входа
- Класс `HabitsApp` наследует от `kivy.app.App`
- Настройка конфигурации приложения
- Инициализация `ScreenManager` и главного экрана
- Управление жизненным циклом приложения

#### 2. **MainTrackerScreen** - Главный экран
- Базовый класс экрана трекера привычек
- Заглушки для методов навигации
- Подключение к .kv файлу разметки

#### 3. **AppStateManager** - Менеджер состояния
- Управление состоянием приложения
- Инициализация и очистка ресурсов
- Подготовка к интеграции с базой данных

#### 4. **main_tracker.kv** - Разметка интерфейса
- Структура главного экрана
- Заголовок и навигация по датам
- Сетка для таблицы привычек
- Статусная строка

### 🔧 Конфигурация

#### requirements.txt
- `kivy>=2.1.0` - основной фреймворк
- `kivymd>=1.1.1` - Material Design компоненты
- `python-dateutil>=2.8.2` - работа с датами
- Инструменты разработки (pytest, black, flake8)

#### config.ini
- Размеры окна: 800x600 (минимум 600x400)
- Настройки ввода и мыши
- Уровень логирования
- Время двойного клика

#### buildozer.spec
- Конфигурация для Android упаковки
- Разрешения файловой системы
- Ориентация: портрет
- Версия: 1.0

### 🚀 Скрипты запуска

#### run_dev.py
- Режим разработки с отладкой
- Загрузка конфигурации из config.ini
- Улучшенное логирование
- Удобный интерфейс запуска

## Как запустить

### Установка зависимостей
```bash
cd kivy
pip install -r requirements.txt
```

### Запуск в режиме разработки
```bash
python run_dev.py
```

### Обычный запуск
```bash
python main.py
```

## Архитектурные решения

### 🎯 Следование принципам
- **Разделение ответственности**: четкое разделение на модели, экраны, виджеты, сервисы
- **Переиспользование кода**: максимальное сохранение логики из веб-версии
- **Кроссплатформенность**: подготовка к Android/iOS упаковке
- **Расширяемость**: модульная структура для легкого добавления функций

### 📱 Kivy-специфичные решения
- Использование ScreenManager для навигации
- .kv файлы для декларативной разметки
- Builder pattern для загрузки интерфейсов
- Событийная модель для обработки взаимодействий
