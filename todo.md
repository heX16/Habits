## def _setup_midnight_check(self):

функционал "проверки полночи и обновления страницы в полночь" не имеет смысла в нативном приложении в приложении.
это только для браузера.

Но при этом в нативном приложении имеет смысл делать другие проверки.
1. когда приложение было снято с паузы, нужно сразу проверять дату модификации DB, чтобы отследить, что файл изменился.

2. нужно следить за изменением DB когда приложение активно. Приложение открывает DB, загружает оттуда данные и сразу же закрывает DB. Это нужно чтобы DB не была защищена от записи (другое приложение может туда писать). И приложение должно следить за тем, что файл изменился. То есть нужно вешать какой-то нотификатор. Это должно быть не отслеживание изменений времени, а именно штука, которая следит, что файл изменился. То есть это системный notification о изменении файла. Если такой системный notification недоступен, то тогда вешать проверку по времени - например раз в минуту проверять дату модификации файла.
